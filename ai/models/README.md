# Artefak penelitian

Pipeline pelatihan hanya menghasilkan model berstatus `research`. Layanan inferensi tidak memuat artefak secara otomatis. Aktivasi memerlukan tinjauan independen, kalibrasi, kajian generalisasi, dokumentasi bias, dan integrasi registry yang disetujui. Jangan memuat joblib/pickle dari pihak yang tidak dipercaya.
